# Local Transcriber Pro 3.4.0

**Une interface organisée autour de votre texte, avec OpenAI Whisper en priorité.**

- Cinq usages à gauche ; source et langues au-dessus du transcript ; paramètres de reconnaissance, voix et stockage dans une fenêtre dédiée.
- Profil Précision OpenAI : Whisper large-v3 complet sur le matériel compatible, avec les contrôles de mémoire conservés. Tous les modèles manuels, la rapidité et la couverture maximale restent disponibles.
- Recherche Ctrl+F, navigation au clavier, recherche logique de l’arabe et limite de 1 000 résultats ; F11 conserve la lecture agrandie.
- Lecture au clic dans chaque langue, écran interlocuteur, traduction bidirectionnelle et troisième langue, révision, réponses écrites/lues, confidentialité, fichiers/vidéos et exports conservés.
- Le micro est surveillé uniquement dans les usages microphone. Les changements de langue conservent la conversation et l’écran interlocuteur. Les informations de modèle suivent le moteur chargé.
- Aide bilingue, README et dix captures réelles actualisés. Mises à jour signées ; versions Windows complète/CPU et paquets Mac/Linux expérimentaux.

Tout traitement vocal, texte et traduction préparé reste local. Les téléchargements demandés nécessitent Internet. Les paquets macOS arm64 et Linux x86-64 restent expérimentaux ; aucun test physique de micro ou GPU sur ces systèmes n’est revendiqué.
